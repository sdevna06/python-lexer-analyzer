# Creative Lexical Analyzer

A Python-based Lexical Analyzer project developed using Tkinter and Regular Expressions.

This project demonstrates compiler design concepts by scanning source code and classifying tokens such as keywords, identifiers, operators, symbols, numbers, comments, and strings.

---

## Features

- GUI-based lexical analyzer
- Syntax token classification
- File upload support
- Color-coded token output
- Keyword recognition
- Invalid token detection
- Compiler design concepts implementation

---

## Technologies Used

- Python
- Tkinter
- Regular Expressions (Regex)

---

## Token Types Supported

| Token Type | Example |
|------------|---------|
| KEYWORD | int, if, while |
| IDENTIFIER | variableName |
| NUMBER | 123 |
| OPERATOR | +, -, *, = |
| SYMBOL | ; { } ( ) |
| STRING | "Hello" |
| COMMENT | // comment |
| INVALID | @ # ^ |
